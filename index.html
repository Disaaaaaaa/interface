1. What is a user interface?

A user interface (UI) is the part of a computer system through which a user communicates with hardware and software. It accepts user input, sends instructions to the operating system or application, and presents output back to the user.

User
clicks, types, speaks, gestures
⇄
User Interface

Four interface types in this unit

GUI

Graphical

Windows, icons, menus, buttons, pointer/touch.

CLI

Command Line

Text commands typed into a shell or terminal.

NLI

Natural Language

Everyday spoken or written language.

GRI

Gesture Recognition

Physical gestures interpreted as commands.

Important: Modern systems often use several interface types at the same time. A smartphone, for example, mainly uses a GUI but also accepts touch gestures, voice commands and typed natural-language search.

Interactive Interface Explorer

GUI: The user selects visible objects. Typical input: mouse, touchpad, touchscreen. Strong discoverability; comparatively high resource use.
CLI: The user types exact commands. Excellent for automation and expert control; commands must be learned and entered accurately.
NLI: The system interprets everyday language such as “Open my downloads folder” or “Find documents created yesterday.” Easy to express intentions, but language can be ambiguous.
GRI: The system detects gestures such as swipe, pinch, rotate, hand movement or body pose. Direct and intuitive for some tasks, but tiring or inaccurate in unsuitable environments.

2. Graphical User Interface (GUI)

A Graphical User Interface allows users to interact with a computer using graphical objects such as windows, icons, menus, buttons, dialog boxes and pointers. Many GUIs follow the WIMP model: Windows, Icons, Menus, Pointer.

Common GUI components

  • Windows: areas showing applications or documents.
  • Icons: graphical symbols representing files, apps or functions.
  • Menus: lists of commands or options.
  • Pointer / cursor: used to select or manipulate objects.
  • Buttons and controls: clickable elements that trigger actions.
  • Dialog boxes: ask users for information or confirmation.
  • Drag-and-drop: direct manipulation of visible items.

Typical OS examples

  • Microsoft Windows: desktop, Start menu, taskbar, File Explorer.
  • macOS: Finder, Dock, menu bar, Mission Control.
  • Linux desktop environments: GNOME, KDE Plasma, Cinnamon.
  • Mobile operating systems: icon grids, touch controls, settings panels and app switchers.

Advantages of GUI

  • Easy to learn because commands are represented visually.
  • Users do not need to memorise many command names or syntax rules.
  • Good for beginners and occasional users.
  • Visual feedback makes current state and available options easier to understand.
  • Supports direct manipulation such as dragging, resizing and selecting.
  • Good for graphics-heavy tasks such as design, image editing and presentation work.
  • Can make multitasking easier by displaying several windows simultaneously.
  • Menus and icons reduce spelling and syntax errors.
  • Touch-friendly GUIs work well on mobile and tablet devices.

Disadvantages of GUI

  • Requires more RAM, storage and graphics processing than a simple CLI.
  • Can be slower for repetitive expert tasks.
  • Automation is often more difficult than writing a script.
  • Complex menus can hide advanced features.
  • Precise control may require many clicks and dialog boxes.
  • Remote administration can consume more bandwidth than text-based access.
  • Some visual interfaces create accessibility barriers unless designed properly.
  • Large numbers of icons, panels and notifications can cause clutter.
Exam technique: Do not write only “GUI is easier.” State why: “A GUI is easier for inexperienced users because visible icons and menus reduce the need to memorise command syntax.”

3. Command Line Interface (CLI)

A Command Line Interface allows users to type text commands into a shell or terminal. The system interprets each command and returns text output.

OS examples

  • Windows: Command Prompt and PowerShell.
  • macOS: Terminal, commonly using the zsh shell.
  • Linux: terminals using shells such as Bash, zsh or fish.
  • Servers/network devices: often managed remotely through text-based terminals because they are fast and bandwidth-efficient.

Basic CLI concepts

  • Command: instruction such as cd, ls or mkdir.
  • Argument: extra data supplied to a command.
  • Option / flag: changes how a command behaves.
  • Prompt: shows the shell is ready for a command.
  • Script: saved sequence of commands that can run automatically.

Interactive CLI simulator

MiniShell 1.0 — type help to see supported commands.
student@school:~$

Try: help, ls, pwd, mkdir revision, echo hello, clear.

Advantages of CLI

  • Fast for experienced users.
  • Consumes relatively few system resources.
  • Efficient over slow or remote connections because text data is small.
  • Excellent for automation using scripts, loops and pipelines.
  • Commands can be highly precise and repeatable.
  • Advanced functions may be available even when no GUI option exists.
  • Useful for system administration, server management and development.
  • Commands can be copied, documented and reused.

Disadvantages of CLI

  • Commands and syntax must be learned or looked up.
  • Spelling mistakes and incorrect parameters can cause errors.
  • Less discoverable because available commands may not be visible.
  • Can appear intimidating to inexperienced users.
  • Some destructive commands can have serious consequences if used incorrectly.
  • Not ideal for visual tasks such as image editing or page layout.
  • Feedback may be less intuitive than graphical feedback.
Precision point: A CLI is not automatically “better” or “faster.” It is usually faster for trained users and repeatable tasks. For a beginner carrying out an unfamiliar task, a GUI may be faster because commands do not need to be memorised.

5. Natural Language Interface (NLI)

A Natural Language Interface allows a user to communicate with a computer using everyday human language rather than formal commands. Input may be spoken or written.

Examples

  • Voice assistants and voice control features.
  • Dictation and speech-to-text systems.
  • Chatbots and conversational assistants.
  • Natural-language search such as “find photos from last week”.
  • Accessibility tools that let users control a device by speaking.

How it works conceptually

Human language
→
Language processing → intended action

Advantages of NLI

  • Users can communicate in familiar language instead of memorising commands.
  • Can be hands-free, useful while driving, cooking or carrying equipment.
  • Supports accessibility for users who have difficulty using a keyboard or mouse.
  • Can make complex requests concise: one sentence may replace many menu steps.
  • Useful for conversational search and help systems.

Disadvantages of NLI

  • Natural language is ambiguous; the same sentence can have several meanings.
  • Speech recognition may be affected by accents, noise or microphone quality.
  • Privacy can be a concern when spoken requests are captured or processed.
  • Not suitable in every environment, for example quiet exam rooms or noisy factories.
  • Interpretation errors can make results unpredictable.
  • Users may not know what kinds of requests the system understands.
High-quality point: NLI reduces the need to learn computer-specific syntax, but it replaces syntax problems with interpretation problems such as ambiguity and recognition accuracy.

6. Gesture Recognition Interface (GRI)

A Gesture Recognition Interface allows a computer to interpret physical movement as input. Gestures may be detected by a touchscreen, touchpad, camera, depth sensor, motion controller or wearable sensor.

Touch gestures

Tap, swipe, pinch, rotate, long press.

Hand/body gestures

Waving, pointing, hand poses or full-body movements detected by sensors.

Motion control

Tilting or moving a controller, phone or wearable device.

Advantages of GRI

  • Can feel natural because actions resemble real-world movements.
  • Useful when a keyboard or mouse would be inconvenient.
  • Supports immersive systems such as games, AR and VR.
  • Touch gestures allow direct manipulation of on-screen objects.
  • Can improve accessibility for some users.
  • Can reduce dependence on physical buttons.

Disadvantages of GRI

  • Gestures may be interpreted incorrectly.
  • Some gestures are not obvious and must still be learned.
  • Extended use can cause fatigue, especially large arm movements.
  • Cameras and sensors may be affected by lighting, obstacles or distance.
  • Accidental gestures can trigger unwanted actions.
  • Special hardware may increase cost.
  • Some users may be unable to perform certain gestures comfortably.
Distinction: A touchscreen GUI and a gesture interface can overlap. The GUI describes the graphical presentation; gesture recognition describes one way the user controls it.

7. Hybrid and multimodal interfaces

Real operating systems rarely use only one interface type. A multimodal interface combines several input methods so the user can choose the most suitable one.

Laptop

GUI + keyboard shortcuts + terminal + voice dictation + touchpad gestures.

Smartphone

Touch GUI + swipe/pinch gestures + voice assistant + natural-language search.

Server workstation

GUI for monitoring + CLI for scripts and remote administration.

Why hybrid designs matter: Different interfaces are best for different tasks. A GUI can make a system easy to learn, while a CLI can provide automation and precision. NLI can improve hands-free access, while gestures can make spatial manipulation more direct.

Activity C — Explain, do not just name

Complete each sentence mentally, then reveal the model answer.

Why can a CLI be more suitable for a low-powered server?

Because a CLI does not need to render a graphical desktop and therefore normally consumes fewer system resources. It also supports efficient remote administration and scripting.

Why can a GUI be safer for an inexperienced user?

Menus, buttons and dialog boxes limit the actions available and reduce command-syntax errors. Confirmation dialogs may also prevent accidental destructive actions.

Why can NLI be convenient but unreliable?

It lets users express intentions in ordinary language, but ordinary language can be ambiguous and speech recognition can be affected by noise or pronunciation.

Why might GRI be unsuitable for long periods?

Large or repeated physical movements can cause fatigue, and recognition accuracy can decrease when sensors cannot clearly detect the gesture.

Key exam verbs

  • Identify: state the feature, advantage or disadvantage.
  • Explain: give the point and show why it matters.
  • Compare: describe both sides using a common criterion.
  • Justify: select an interface and link its features to the specific scenario.
Best revision rule: Avoid absolute statements such as “CLI is always faster” or “GUI is always easier.” Interface suitability depends on the user, task, environment and hardware.
